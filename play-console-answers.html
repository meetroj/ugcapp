Still needs you

1. Reviewer test account — blocks submission

Create a brand account and finish the profile onboarding. The app gates its dashboard behind profile_completed, so a half-set-up account looks broken to a reviewer.

Name it "Brand account", then paste the email and password into the App access form.

2. Upload the AAB, not the APK

New apps must ship as an Android App Bundle. Use ugcad-release.aab (53.3 MB). The APK is for testing on a device only.

3. Bump versionCode before uploading

It is still 1. Play rejects duplicate version codes on every later update.

4. Google Cloud Console — only if you want OAuth live

Register an Android OAuth client on package com.ugcapp with the debug SHA-1 5E:8F:16:06:2E:A3:CD:2C:4A:0D:54:78:76:BA:A6:F3:8C:AB:F6:25, plus your release and Play App Signing SHA-1s.

Until then the Google button fails with DEVELOPER_ERROR — which is why the account-creation answer stays "Username and password".
